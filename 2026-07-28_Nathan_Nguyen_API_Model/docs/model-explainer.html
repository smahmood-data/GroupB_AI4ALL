How the dengue forecast works

The model studies past dengue cases, weather, and seasonality. It produces one output optimized for accurate weekly case counts and a second output that is more willing to warn about possible outbreaks.

The key idea: predicting the number of cases and catching outbreaks are related, but they are not the same job. The notebook keeps them separate.

The whole architecture at a glance

Follow the arrows from raw weekly information to the three outputs that are compared in the notebook.

Model 1

Single-stage model

This model learns one direct connection between the available information and the number of cases expected that week.

  1. Read the weather, season, and earlier case history.
  2. Find patterns that previously led to low or high case counts.
  3. Return one weekly case estimate.
  4. Use that estimate when preparing the following week.
Strength: stable and comparatively simple. It is the baseline every more complicated model must beat.
Model 2

Two-stage outbreak model

This model first asks, “Does this look like an outbreak week?” It then chooses between two case-count specialists.

  1. Estimate how outbreak-like the week appears.
  2. Adjust that score using earlier years so it behaves more like a real probability.
  3. Ask both specialists for a case estimate: one trained on ordinary weeks and one trained on high-case weeks.
  4. Use a decision line to choose one specialist’s answer.
Why no averaging? MAE rewards a middle answer. Averaging an ordinary estimate with an outbreak estimate can land in an unhelpful middle ground.

How the notebook decides that a week is an outbreak

1

Look at the same season

For week 30, use historical weeks 28–32. The window wraps correctly around New Year.

2

Find the upper quarter

The level exceeded by only the highest 25% of those historical case counts becomes that season’s outbreak line.

3

Compare the current week

If the real count reaches or exceeds that training-only line, evaluation marks it as an actual outbreak week.

This is a statistical project definition, not an official public-health declaration. Crucially, the held-back test year never helps set its own outbreak line.

Why the outbreak specialist has enough examples

Training only on the highest 25% left too few examples. The revised specialist also learns from “near-outbreak” weeks in the highest 40% for that season. Genuine outbreak weeks receive twice the importance during training.

What happens when predicting a new week?

  • Collect weather
  • Add past-case memory
  • Estimate outbreak likelihood
  • Choose a specialist
  • Predict cases
  • Carry prediction forward
No future-answer shortcut: later test weeks receive earlier predictions, not hidden real case counts.
No future-weather filling: missing values are filled using training history and earlier observations only.

What is working well

  • The validation process respects time instead of randomly mixing weeks.
  • Seasonal outbreak lines are more meaningful than one city-wide cutoff.
  • The outbreak specialist now has more training support.
  • The best case-count MAE improved from 11.68 to 11.09.
  • The recall policy is markedly better during outbreak weeks.

What still needs work

  • Outbreak alerts catch only about half of the outbreak weeks.
  • Most warnings are false positives.
  • San Juan’s largest spikes remain difficult.
  • The data are small, so results change considerably between years.
  • The outbreak label is statistical, not an official epidemiological definition.

Weekly case-count architecture

Three regressors produce a median estimate (P50) and two cautious upper estimates (P80 and P90). P50 is scored with MAE. When exact recent case reports exist, the model predicts the change from last week and adds that change to the last known count. This is easier than relearning the epidemic's current level from scratch.

Important limitation: without recent reports, weather alone has 59.81 MAE. That fallback is labeled limited_no_exact_recent_cases and its case number should be treated cautiously.
The upper ranges are not fully calibrated yet: P80 contained 68.8% of held-out outcomes and P90 contained 76.0%, rather than 80% and 90%. They are useful research signals, not guaranteed bounds.
